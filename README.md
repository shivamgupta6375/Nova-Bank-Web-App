# Nova Bank - Web Application

A banking web application created using HTML, CSS, and JavaScript with the assistance of ChatGPT AI.

## Features
- User Registration and Login
- Deposit and Withdraw Money
- Check Account Balance
- View Account Details
- Change Password

## Technologies Used
- HTML
- CSS
- JavaScript
- ChatGPT AI

## AI Assistance
This web application was developed with the help of ChatGPT AI. The original C++ Bank Management System project was used as a reference for its functionality and logic.

The web application and the C++ project are separate and are not directly connected.

## Related Project
**C++ Bank Management System:** [View Repository](https://github.com/shivamgupta6375/Bank-Management-System-CPP)

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Explore the available features.

## Disclaimer
This project is intended for educational purposes only. It is a frontend prototype and does not support real banking transactions. User data is stored in the browser and is not securely managed.
